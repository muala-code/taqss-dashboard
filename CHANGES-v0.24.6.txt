طقس داشبورد — تحديث 0.24.6

المصحف:
- شريط علوي مباشر: خيارات، قراءة، معلومات السورة والجزء، استماع، ملء الشاشة.
- إزالة اختيار القراءة والاستماع من نافذة الخيارات.
- إظهار إطار مساحة التلاوة أو إخفاؤه، مع حفظ الاختيار.
- تشغيل البسملة بصوت القارئ قبل الآية الأولى في مصادر EveryAyah، عدا الفاتحة (بسملتها هي الآية الأولى) والتوبة. تسجيلات السورة المتصلة تبدأ من بداية الملف الحالية دون إضافة بسملة ثانية.
- البسملة مرحلة صوتية مستقلة؛ توقيتات الكلمات الأصلية لا تتغير، والتكرار يشمل الآية دون إعادة البسملة.
- قفل اختيار القارئ أثناء التشغيل والتجهيز، وإتاحته بعد الإيقاف المؤقت. الاستئناف يحافظ على موضع التوقف. تغيير القارئ بعد التوقف يبدأ من الآية الحالية.
- منع طلب تشغيل قديم من إيقاف طلب تشغيل أحدث.

الأسعار:
- عنوان مؤشرات ثابت بخلفية مميزة.
- أسماء عربية: تاسي، داوجونز، ناسداك، الذهب، الفضة، برنت، نايمكس، إس تي سي.
- حركة تلقائية مع السحب اليدوي في الاتجاهين وأسهم تحريك ولوحة المفاتيح.
- الاحتفاظ بموضع الشريط عند تحديث الأسعار وإيقاف الحركة التلقائية عند التفاعل أو تفضيل تقليل الحركة.

التثبيت:
انسخ الملفات الستة وملف التغييرات إلى مجلد E:\taqss-dashboard واستبدل النسخ الموجودة، ثم نفذ كل سطر منفصلًا:
cd /d E:\taqss-dashboard
git add index.html app.js styles.css mushaf.js mushaf.css markets-config.js CHANGES-v0.24.6.txt
git commit -m "Improve mushaf controls, basmala and Arabic ticker"
git push origin main
