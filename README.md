# طقس داشبورد

واجهة Static خفيفة للجوال أولًا، بالاتجاه العمودي، لمحطة IMEDIN86 قرب أبيار الماشي.

## التبويبات

- الطقس: جميع قيم WU المتاحة، مع العظمى/الصغرى واتجاه الرياح الحالي.
- التاريخ: شارت واحد في كل مرة من قائمة اختيار: حرارة اليوم، حرارة/مطر السنة، ومتوسط الحرارة/نقطة الندى للشهر. حرارة اليوم تعرض اليوم الحالي فقط؛ الشارت الشهري يسمح بالتنقل بين الأشهر، والسنوي بين السنوات المتاحة منذ بداية تسجيل المحطة.
- الرادار: RainViewer + OpenStreetMap، إطارات متحركة، السابق/التالي، إعادة تمركز، وملء الشاشة.
- الأسعار: تاسي، الذهب، الفضة، برنت، نايمكس، والأسهم المحددة في markets-config.js.
- أوقات الصلاة: اليوم، الهجري، الميلادي، أوقات الصلاة، وبيانات القمر التي يعيدها عامل المحطة.

## التشغيل المحلي

شغّل `start-local.bat` أو:

```text
py server.py
```

ثم افتح `http://localhost:8080`.

## API

الوضع الافتراضي في `config.js` يستخدم عامل «المحطة» الحالي للطقس والتاريخ والصلاة، لذلك يمكن تجربة هذه التبويبات مباشرة.

لتفعيل الأسعار وإظهار `rawObservation` الكامل من WU عند تشغيل العامل مباشرة بمفتاح WU:

1. انشر `worker.js` كعامل Cloudflare جديد.
2. يمكن تشغيله بلا مفتاح WU؛ حينها يمرر خدمات الطقس القديمة ويضيف الأسعار.
3. يمكن إضافة `WU_API_KEY` كـ Secret لاحقًا إذا أردنا أن يجلب العامل الجديد WU مباشرة بدل تمرير الطلبات.
4. ضع رابط العامل في `dashboardApiBase` داخل `config.js`.

## تعديل قائمة الأسهم

كل القائمة موجودة في ملف واحد: `markets-config.js`.

للإضافة:

```js
{ symbol: "1211.SR", name: "معادن", category: "stock", enabled: true }
```

للإخفاء بدون حذف السطر:

```js
enabled: false
```

التصنيفات المستخدمة: `index` و`commodity` و`stock`.

## ملاحظة الأسعار

مصدر الأسعار الحالي هو Yahoo Finance عبر chart endpoint. السعر يقارن بالإغلاق السابق، والواجهة تعرض الارتفاع بالأخضر والانخفاض بالأحمر وعدم التغير بلون النص العادي. الأسعار قد تكون متأخرة.


## التنقل في شارتات التاريخ

- حرارة اليوم: لا يوجد تنقل؛ تعرض اليوم الحالي فقط.
- متوسط الحرارة ونقطة الندى: أزرار السابق/التالي للتنقل بين الأشهر، وكل نقطة تمثل متوسط الحرارة ونقطة الندى لذلك اليوم من الشهر، وكلاهما بالدرجة المئوية.
- الحرارة والمطر سنويًا: أزرار السابق/التالي للتنقل بين السنوات المتاحة.
- أقدم فترة مسموحة مبنية على `stationStartDate` في `config.js`، وهي افتراضيًا 2026-06-05.
